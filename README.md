# Automated Waste Collection System for River Eco-System

## Description

This project is an automated river cleaning system designed to collect both floating and underwater waste materials using conveyor and robotic arm mechanisms.

## Features

* Surface waste collection
* Underwater waste collection
* Bluetooth control
* Arduino UNO and ESP32 based system
* IoT monitoring support

## Components Used

* Arduino UNO
* ESP32
* L293D Motor Driver
* DC Motors
* Servo Motor
* HC-05 Bluetooth Module
* Conveyor Belt
* Robotic Arm
* Ultrasonic Sensor
* IR Sensor

## Working

The conveyor belt collects floating waste from the water surface, while the robotic arm removes underwater waste. Sensors detect waste materials and the controller manages motor and robotic operations automatically.

## Applications

* River Cleaning
* Lake Cleaning
* Waste Management
* Environmental Protection
